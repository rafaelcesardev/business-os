# Conhecimento

Aprendizados e referências de negócio que orientam decisões desta empresa: resumos de
artigos, cursos, livros e lições tiradas da própria operação.

Um arquivo por tema, com a fonte e a data no topo. Guarde o que muda uma decisão, não
tudo que foi lido. O que virar regra da empresa segue para o arquivo do assunto
(`mensagem.md`, `negocio.md`, `processos/`).
